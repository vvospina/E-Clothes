# Microservicio de Consejos (consejos-service)

Microservicio backend desarrollado con **Django REST Framework** y **MongoDB** para la gestión de consejos ambientales dentro del sistema E-Clothes. El proyecto implementa un modelo de seguridad basado en autenticación por Firebase y estructuración modular por componentes.

python -m venv venv
# En Windows:
